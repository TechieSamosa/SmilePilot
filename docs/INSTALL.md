# Installing SmilePilot / Brace Place

## Android (APK)

1. Tap the `SmilePilot-<version>.apk` file you received → **Install**.
2. If the phone says installing from this source is not allowed: **Settings** → turn on **Allow from this source** → back → **Install**.
3. If Play Protect warns about an unknown app: **More details → Install anyway** (the app is not on the Play Store).
4. Updates: install the newer APK the same way — records stay. Do not uninstall first.

## iPhone (web app)

1. Open the app link in **Safari** (not Chrome, not the WhatsApp in-app browser).
2. Tap **Share** (square with arrow) → **Add to Home Screen** → **Add**.
3. Always open it from the new Home Screen icon. Once opened on Wi-Fi it works offline.
4. Tip: **More → Settings → Download for offline** once, so X-ray AI works without internet.

## First start

1. Check the pre-filled doctor and clinic details; add the registration number. They print on prescriptions.
2. Set a 4-digit PIN.
3. Done — everything is free and works on the phone without internet or any account.

## Keep data safe

Records live only on the phone. Once a week: **More → Backup & restore → Back up now** → save to Google Drive / iCloud
Drive or send to yourself on WhatsApp. The backup restores on any phone (Android ↔ iPhone).

## Optional: Pro AI agent

**More → Pro AI agent** explains how to create your own Claude API key (Anthropic Console → Billing → API keys) and paste
it in Settings. It adds an AI assistant that can find patients, check the schedule, book appointments and update aligners
(always asking first). A Claude Pro subscription on claude.ai does **not** include an API key.

> Decision-support tool: AI findings can be wrong or incomplete — always verify clinically.
